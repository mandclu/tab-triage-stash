Prefer a saved tab group? Free the memory manually in 4 steps
  1. Make sure the Bookmarks Bar is visible — Cmd/Ctrl+Shift+B.
  2. Select the tabs you want to keep, right-click one, and choose Add tabs to new group. Name and color the group.
  3. Right-click the colored group header and toggle Save group. A pill appears on your Bookmarks Bar.
  4. Right-click the header again and choose Close group. The tabs close and free their RAM; click the pill anytime to reopen them exactly as they were.

This uses Chrome's built-in saved groups. The extension can't do it for you — Chrome doesn't expose an API to save a group — but the Stash controls below give you the same "close now, reopen later" result via a bookmark folder.
